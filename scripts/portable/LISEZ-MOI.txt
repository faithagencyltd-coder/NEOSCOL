NéoScol — démonstration locale (Windows, sans Docker)
=====================================================

CE QU'IL FAUT
  - Windows 10 ou 11 (64 bits)
  - Node.js 20 ou plus, version « LTS » : https://nodejs.org
    (vérifier : ouvrir « Invite de commandes » et taper  node -v)
  - 2 Go d'espace disque libre

LANCER
  1. NéoScol est livré en 3 fichiers .zip :
       NeoScol-1-application.zip, NeoScol-2-postgresql.zip, NeoScol-3-services.zip
     Pour CHACUN des 3 : clic droit > « Extraire tout… » > dans la case du dossier,
     écrivez   C:\   puis « Extraire ».
     Les 3 se rangent alors dans le même dossier  C:\NeoScol
  2. Ouvrez C:\NeoScol et double-cliquez sur  DEMARRER.cmd
     - Premier lancement : 1 à 3 minutes (création de la base de données).
     - Si Windows affiche « Windows a protégé votre ordinateur » :
       cliquez « Informations complémentaires » puis « Exécuter quand même ».
     - Si le pare-feu Windows pose une question : « Autoriser » (réseaux privés).
  3. Le navigateur s'ouvre sur http://localhost:3000
     Choisissez un profil dans « Accès rapide — démonstration ».

UTILISER SUR LES AUTRES APPAREILS (MÊME WI-FI)
  Téléphones, tablettes et autres ordinateurs connectés au MÊME Wi-Fi que ce poste
  peuvent utiliser NéoScol dans leur navigateur, sans rien installer :
  1. Lancez DEMARRER.cmd sur ce poste (il doit rester allumé et la fenêtre ouverte).
  2. La fenêtre affiche l'adresse à ouvrir, par exemple :
         Sur les autres appareils du même Wi-Fi :  http://192.168.1.20:3000
  3. Tapez cette adresse dans le navigateur du téléphone ou de la tablette.
  4. Si la page ne s'ouvre pas : double-cliquez sur  AUTORISER-WIFI.cmd  (accepter la
     demande administrateur) et vérifiez que le Wi-Fi est un « réseau privé » dans
     Windows (Paramètres > Réseau et Internet > Wi-Fi > Profil réseau : Privé).
  Chacun se connecte avec son propre compte. Le « Lien des portails » (menu Portails)
  et ses QR codes utilisent automatiquement cette adresse Wi-Fi.
  Hors du Wi-Fi (Internet), NéoScol n'est pas accessible : c'est une installation locale.

ARRÊTER
  Fermez la fenêtre noire (ou Ctrl + C dedans).
  Les données sont conservées dans le dossier « donnees ».

REMETTRE À ZÉRO
  Double-cliquez sur  REINITIALISER.cmd

EN CAS DE PROBLÈME
  - « le port 3000 est déjà utilisé » : une autre fenêtre NéoScol (ou un autre
    serveur, par ex. « npm run dev ») est ouverte : fermez-la puis relancez.
  - Les journaux détaillés sont dans  donnees\journaux
  - Les données restent sur cet ordinateur : rien n'est envoyé sur Internet.
    Seuls les appareils du même réseau local peuvent ouvrir l'application.

Contenu : application NéoScol, PostgreSQL 17, GoTrue (authentification),
PostgREST (API). Données entièrement fictives.
